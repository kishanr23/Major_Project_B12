To address these challenges, this project presents an effective low-light image enhancement framework that combines classical image processing techniques with a deep learning–based convolutional neural network. Initially, the input image undergoes preprocessing using Contrast Limited Adaptive Histogram Equalization (CLAHE) to improve local contrast, followed by wavelet-based denoising to suppress noise while preserving edge information. A modified Retinex algorithm (MSRCR-Lite) is then applied to enhance illumination and maintain color consistency by modeling human visual perception. The enhanced output is further refined using a CNN-based encoder–decoder architecture, where hierarchical features are extracted through the encoder, compressed at the bottleneck, and reconstructed by the decoder to restore fine details and spatial resolution. This hybrid approach effectively enhances brightness, contrast, and detail while minimizing noise and visual artifacts. Experimental results demonstrate that the proposed method produces visually pleasing and natural-looking enhanced images, making it suitable for real-world low-light imaging applications such as These typically include poor brightness, significant color distortion, and high levels of digital noise. Such degraded images pose a substantial challenge to modern computer vision systems, negatively impacting the reliability and performance of critical applications such as autonomous driving, where object detection is paramount, surveillance systems, which must operate 24/7, and medical imaging, where detail and clarity are non-negotiable. Traditional enhancement methods, such as Histogram Equalization and Gamma Correction, are often insufficient as they tend to be blunt instruments, failing to preserve fine details and sometimes even introducing new artifacts. To overcome these significant limitations, this project proposes a robust deep learning-based low-light enhancement system. This system is fundamentally built upon Retinex theory, which models an image as a product of its illumination and reflectance components. Integrated approach features a dedicated decomposition network to separate these components, an intelligent denoising network to suppress noise without losing texture, and an attention-based enhancement module (FEM) designed to meticulously recover fine details and eliminate common artifacts like haloing.1.2 ObjectiveThe primary objective of this project is to design and develop a novel Retinex-based deep learning model specifically for the task of image decomposition and enhancement. A core goal is to successfully integrate a sophisticated attention mechanism within this model to facilitate more effective and targeted feature learning. This will allow the network to intelligently focus on relevant image regions and features.Furthermore, the project aims to demonstrably improve standard image quality metrics Deviation (GMSD), setting a new benchmark compared to existing state-of-the-art methods.Finally, a key technical objective is to effectively handle and mitigate the complex challenges inherent in low-light enhancement. 1.3 Need for the ProjectThe successful implementation of this project has a wide-ranging scope, with direct applicability in several high-impact domains. Its primary application lies in enhancing the robustness of autonomous vehicles by providing cleaner visual data to perception systems, especially during night-time or adverse weather conditions. It is equally applicable to security and surveillance systems, enabling clearer footage from cameras operating in low light. In the field of medical imaging, this method can be used to enhance the clarity of endoscopic or microscopic images, aiding in diagnostics.Beyond direct enhancement, this system is designed to be a powerful preprocessing step. By improving the quality of input images, it can significantly boost the accuracy of subsequent high-level computer vision tasks such as object detection and semantic segmentation, which traditionally perform poorly on degraded data.Looking forward, the architectural principles of this model can be optimized and extended for real-time video enhancement, broadening its scope to include live video feeds from drones, dashboard cameras, and other mobile devices in future work.1.4 Existing System and its DrawbacksThe landscape of low-light image enhancement is populated by several categories of methods, each with distinct drawbacks. Traditional methods, which include Histogram Equalization and Gamma Correction, are computationally simple but functionally naive. While they can increase global brightness, they often do so at the cost of detail, leading to over-enhancement in bright regions, loss of contrast, and significant color distortion.Retinex-based methods offer a more physically-grounded approach by separating illumination and reflectance. However, classical Retinex algorithms frequently suffer from halo effects, particularly around sharp edges, and can exhibit detail loss in complex lighting scenarios where the illumination map is difficult to estimate accurately.Post-processing denoising techniques, such as the popular BM3D algorithm, are effective at removing noise but are "blind" to the enhancement process. When applied after enhancement, they often remove not only noise but also fine-grained image details and textures, resulting in an overly smooth or "plastic-like" image.More recent Deep learning methods, such as RetinexNet, have shown significant improvement in adaptive enhancement. However, many existing models still struggle with specific artifacts. They often fail to completely remove shadow artifacts in very dark regions and can produce results with uneven or unrealistic illumination, indicating that the separation of components is not yet perfected.1.5 Proposed SystemThe proposed system is an end-to-end, multi-stage deep learning framework that addresses the aforementioned drawbacks in a unified architecture. The process begins with a Retinex-based decomposition network that intelligently separates the input low-light image into its constituent illumination and reflectance maps.This decomposition is immediately followed by passing the reflectance map through an integrated denoising network. This module is specifically designed to suppress noise that becomes amplified during the decomposition process, while crucially preserving essential texture and structural details.The core of the system is a Feature Enhancement Module (FEM) that utilizes both channel and spatial attention mechanisms. This dual-attention approach allows the network to learn what features to emphasize (e.g., colors, fine edges) and where to emphasize them (e.g., dark regions, detailed areas). This targeted enhancement is key to removing shadow blocks and halo effects.Finally, the entire network is trained with a comprehensive loss function. The process begins with a pre-processing stage, which serves to prepare the raw image data. This stage utilizes two specific techniques: CLAHE (Contrast Limited Adaptive Histogram Equalization) to improve local contrast, and wavelet denoising to remove the digital noise or grain that typically affects low-light photography. Following this, the image passes through a modified Retinex module utilizing the MSRCR-Lite (Multi-Scale Retinex with Color Restoration) algorithm. This step is crucial for balancing the lighting and enhancing color fidelity before the deep learning phase begins.The core of the enhancement process takes place in the CNN architecture, which is a deep neural network structured as an encoder-decoder model. Interestingly, the data flow in this diagram moves from right to left within the CNN block. The processed image first enters the encoder on the right side, where it passes through a series of convolutional (CONV) layers, increasing in depth from 32 to 256 channels, and maxpooling layers with 2x2 dimensions. This section extracts high-level features while reducing the image size. The data then flows through a central bottleneck layer consisting of a dense CONV 512 block. Finally, the decoder on the left side reconstructs the image using upsampling layers with 2x2 dimensions and further convolutional layers, gradually restoring the spatial resolution. The final output is a fully reconstructed image with significantly improved brightness, visible details, and corrected contrast.4.2 Low Level DesignFigure 4.2: Low-level design of the proposed hybrid low-light image enhancement framework1. Input and PreprocessingThe pipeline begins at the Input Layer, which accepts low-light images, standardized to a 256*256-pixel resolution for consistent processing. The first major phase is Preprocessing, which focuses on contrast improvement and noise reduction. It utilizes CLAHE (Contrast Limited Adaptive Histogram Equalization) in the LAB color space to boost local contrast without over-amplifying noise, using specific parameters like a clip limit of 2.0. This is paired with Wavelet Denoising (specifically the Haar Transform with soft thresholding), which is crucial for preserving edges while stripping away the graininess often found in low-exposure photography.2. Enhancement via MSRCR-LiteOnce the image is cleaned, it moves to the Enhancement stage, which employs MSRCR-Lite (Multi-Scale Retinex with Color Restoration). This algorithm is designed to mimic human visual perception by balancing illumination across different scales (using scales of 15, 80, and 200). It performs color restoration and gain-offset adjustments to ensure that the brightened image looks natural and vibrant rather than washed out. The "Lite" version suggests an optimization for speed, making it suitable for real-time or resource-constrained applications.3. CNN Refinement and OutputThe most advanced stage is the CNN Refinement, which uses a U-Net Architecture. This deep learning model acts as a "polisher" for the image. By using an encoder-decoder structure with skip connections and residual blocks, the U-Net recovers fine details and textures that may have been blurred during the earlier denoising stages. Instance normalization helps stabilize the learning process. The result is passed to the Output Layer, providing a high-quality, enhanced image that is significantly clearer than the original input.4. Quality AssessmentRunning parallel to the refinement stage is a Quality Assessment module. This is used to objectively measure how much the image has improved. It utilizes three primary metrics:PSNR (Peak Signal-to-Noise Ratio): Measures the ratio between the maximum possible power of a signal and the power of corrupting noise.SSIM (Structural Similarity Index): Evaluates how much the "structure" of the image (patterns and textures) has been preserved.Entropy: Measures the amount of information or "detail" present in the final image.CHAPTER 5                                                IMPLEMENTATION5.1 Module DescriptionThe system is implemented as a single, end-to-end deep learning pipeline, built using the PyTorch framework. Each conceptual module described in the design phase functions as a distinct nn.Module class, allowing for a clean, object-oriented, and modular codebase.1. Data Loading and Preprocessing Module: This module is implemented using PyTorch's Dataset and DataLoader classes. A custom Dataset class is created to load the training data (e.g., LOL-V1/V2), which consists of directories for low-light and corresponding ground-truth image pairs. In the __getitem__ method, images are loaded using OpenCV, converted to tensors, and subjected to data augmentation using torchvision.transforms (e.g., random cropping, horizontal flipping). A normalize transform is applied to scale pixel values to a range (e.g., [0, 1]), which is essential for stable network training. The DataLoader class is then used to batch this data and shuffle it for each epoch, feeding it efficiently to the GPU.2. Retinex Decomposition Module (Decom-Net): This is implemented as a custom nn.Module class. It consists of a lightweight CNN, typically with 5-7 convolutional layers and ReLU activation functions. Skip connections are implemented by concatenating features from earlier layers with features from deeper layers, preserving spatial information. The network takes a 3-channel image as input and has two separate "heads" (two final convolutional layers) that output the 3-channel Illumination (I) map and the 3-channel Reflectance (R) map, respectively. The training of this sub-network is governed by a custom loss function that includes illumination smoothness (e.g., a total variation loss) and a reconstruction loss (I * R should equal the original image).3. Denoising Module (Denoise-Net): This module is another nn.Module class, specifically implementing the Basic Residual Modules (BRM) and dilated convolutions. Each BRM is a small block of convolutional layers where the input to the block is added to its output (a residual connection). This design, inspired by ResNet, helps preserve fine textures that are often lost during denoising. Dilated convolutions are implemented by setting the dilation parameter in the nn.Conv2d layer, which allows the network to have a larger receptive field without increasing the number of parameters or losing resolution.4. Feature Enhancement Module (FEM-Net): This is the most complex module, implemented as a U-Net. The encoder part consists of standard convolutional blocks followed by max-pooling. The decoder part consists of up-sampling layers (e.g., nano- ConvTranspose2d) followed by convolutional blocks. The key implementation detail lies in the skip connections: feature maps from the encoder are not directly concatenated. Instead, they are first passed through a Dual Attention Block (another custom nanomodule) before being concatenated with the corresponding decoder feature map. This attention block contains the sequential Channel Attention and Spatial Attention mechanisms, which apply learned weights to the feature maps.5. Reconstruction Module: This module is not a complex network but rather a simple operation within the main model's forward method. After the FEM-Net outputs the final enhanced Illumination map and the Denoise-Net outputs the clean Reflectance map, this module performs an element-wise multiplication (torch.mul()) to reconstruct the final enhanced image. This final tensor is then compared against the ground-truth image using a combined loss function (e.g., L1 loss + Perceptual VGG loss) to calculate the gradients for backpropagation.5.2 PseudocodeThis algorithm details the process of training the deep convolutional neural network (U-Net) model for color restoration.Tools and MethodologyThe proposed project is developed entirely using Python 3.8 and above, ensuring compatibility with modern deep learning libraries and efficient execution on both CPU and GPU platforms. This design is further strengthened through the use of a compound loss function, formulated as a weighted combination of multiple loss terms such as pixel-wise reconstruction loss (L1), perceptual loss, and illumination smoothness constraints. The compound loss formulation ensures a balanced optimization process by jointly addressing competing objectives, including brightness enhancement, texture preservation, color consistency, and artifact suppression.
